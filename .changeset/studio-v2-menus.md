Studio has a real application menu. In a browser, the header has an accessible File / Edit / View / Go / Run / Help menubar (F10, or tap Alt on Windows/Linux; arrow keys, typeahead and submenus), every item showing its keyboard shortcut, plus a centered "Go to file or run a command" box (a search icon in narrow windows). View ▸ Menu Bar hides the menubar behind a ☰ button. File ▸ Open Recent and Go ▸ Changed on Disk list recent folders, recent files and files an agent changed. The desktop app builds the same menus natively, with checkmarks and recent items that follow the focused window.
